# ECIT
ECIT is a modular, from-scratch Computational Intelligence and Neural Networks framework. Designed without high-level machine learning libraries, it provides a clean, decoupled architecture for matrix operations, transfer functions, single- and multi-layer topologies, and classical learning rules (Hebbian, Perceptron, Delta/LMS, Backpropagation, and Competitive learning).

Developed as the core execution engine for the Computational Intelligence course, ECIT separates mathematical primitives and optimization mechanics from task-specific visualization and GUI interfaces.
